# Data Professional Survey Breakdown

## Project Overview

This project uses Microsoft Power BI to analyze survey data collected from data professionals. The dashboard presents survey findings through interactive visualizations, making it easier to explore information about respondents and compare different aspects of their professional experiences.

## Tools Used

- Microsoft Power BI
- Data visualization
- Data analysis and reporting

## Dashboard Features

The dashboard includes several visualizations to present the survey data, including:

- Donut charts
- Bar and column charts
- Gauge charts
- Summary cards

These visualizations help organize survey results and make the information easier to interpret.

## Skills Demonstrated

- Building interactive dashboards
- Visualizing survey data
- Presenting data through charts and summary metrics
- Designing reports for easier interpretation

## Project File

The Power BI report is available in this repository as a `.pbix` file. Download it to explore the dashboard using Power BI Desktop.
